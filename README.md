# Softmax with temperature — exercises

Hands-on exercises covering:

- 6.1 — softmax probabilities at T = 1
- 6.2 — effect of temperature on the top token
- 6.3 — top-p (nucleus) filtering
- 6.4 — sampling from the distribution

There are two ways to work through them:

## Option A — plain Python scripts

- **`logits.py`** — the part you edit: `LOGITS`, `LABELS`, `TEMPERATURE`,
  `TEMPERATURES_TO_COMPARE`, `TOP_P`, and the core functions
  (`softmax_with_temperature`, `top_p_mask`, `sample_tokens`).
- **`presentation.py`** — imports from `logits.py` and prints the table, temperature
  diffs, top-p breakdown, and sampling comparison, and saves charts to `outputs/`.

Run with:

```bash
python presentation.py
```

Edit the values in `logits.py`, then re-run `presentation.py` to see how the results
change.

## Option B — Jupyter notebook

`exercises.ipynb` covers the same four exercises interactively, cell by cell, plus a
bonus section that:

- downloads a small public dataset (`fancyzhx/ag_news`) and picks a real sentence as a
  prompt
- loads a small free local model (`distilgpt2`, no API key needed) to get **real**
  next-token logits
- applies temperature plus **top-k and top-p together** to the real distribution
- repeats the 6.4 sampling exercise on the real model's distribution

## Setup

1. Create a virtual environment and install the dependencies:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate   # Windows: .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
2. To run the plain scripts: `python presentation.py` (see above).
3. To use the notebook: install Jupyter (`pip install jupyter`) and open
   `exercises.ipynb`, or open it directly in VS Code / JupyterLab. Run all cells
   (Kernel → Restart & Run All) after editing the values.

The first run downloads the `distilgpt2` model weights and a small dataset split, so it
takes a little longer — later runs are fast.

`outputs/` holds charts generated by `presentation.py` and is git-ignored except for a
`.gitkeep` placeholder, since its contents are generated, not hand-written.
